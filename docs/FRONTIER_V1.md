# PUR-FRONTIER V1 — deterministic decision frontier

`PUR-FRONTIER V1` is now **FROZEN**. The definition is in `configs/frontier_v1.json`, the implementation is in `src/pur_science/`, and the frozen outputs are regenerated by `scripts/freeze_frontier_v1.py` from the hash-verified 928-candidate `PUR_SIM_V1` snapshot.

It builds on the historical PUR-ORACLE V2 record without rewriting that version.

## Decision question

```text
property optimum
    -> nominally feasible optimum
    -> uncertainty-robust decision optimum
    -> active boundary
    -> backward threshold
    -> reachable formulation
```

The objective is not only to identify a winner but to determine why the decision changes between layers and whether the correction needed to cross the active boundary lies on the admissible formulation manifold.

## Frozen layers

| Layer | Candidate set | Score |
|---|---|---|
| L0 property-only | all 928 candidates | `J = sum_k w_k log10(y_k/c_k)^2`, with preferred-window geometric centres `c_k` |
| L1 nominal constrained | point responses pass broad and preferred rheology windows, NCO:OH, MDI-fraction and chemistry-domain gates | same nominal `J` |
| L2 robust | L1 candidates whose full propagated uncertainty intervals remain inside the broad functional windows and `domain_ratio <= 1.0` | exact interval worst case of the same objective |

For L2,

```text
J_wc = sum_k w_k (abs(log10(y_k/c_k)) + q_k r)^2
```

with frozen multipliers

```text
q_eta80 = 1
q_eta120 = 1
q_ratio = 2
```

The stored radius `r` represents `log10(eta) +/- r`. Conservative propagation of `ratio = eta80/eta120` gives `log10(ratio) +/- 2r`. No new uncertainty weight, posterior distribution or fitted penalty is introduced.

## Why robust admissibility uses the broad window

The preferred windows define the optimization target, not a certification envelope. Requiring the entire uncertainty interval to remain inside all preferred windows gives zero robust candidates in the frozen 928-candidate space. FRONTIER V1 therefore separates two questions:

1. does the complete uncertain response remain inside the broad functional envelope?
2. among those candidates, which minimizes the worst-case distance to the preferred centres?

This produces a usable parameter-free minimax decision layer without weakening the nominal preferred target.

## Frozen decision chain

The complete response table gives:

```text
928 total candidates
141 L1 nominally feasible
117 L2 robust-admissible

L0 property winner      WO_INV_0419
L1 constrained winner   WO_INV_0579
L2 robust winner        WO_INV_0420
```

### L0 property optimum

`WO_INV_0419` is PPG1000/PPG700 = 50/50 at NCO:OH = 1.7. It has

- `J = 6.3152e-05`;
- eta80 = 3.4260 Pa s;
- eta120 = 0.4200 Pa s;
- eta80/eta120 = 8.1576;
- MDI fraction = 0.340625.

Its only nominal failure is the frozen 35 wt% MDI lower bound.

### L1 nominal constrained optimum

`WO_INV_0579` is PPG2000/PPG400 = 60/40 at NCO:OH = 1.7 and remains the best point-feasible formulation under the nominal objective (`J = 4.1602e-04`).

### L2 robust decision optimum

`WO_INV_0420` is PPG1000/PPG700 = 50/50 at NCO:OH = 1.8. It has

- MDI fraction = 0.353577;
- eta80 = 3.3376 Pa s;
- eta120 = 0.4035 Pa s;
- eta80/eta120 = 8.2714;
- nominal score = 8.3519e-04;
- worst-case robust score = 2.1897e-02;
- domain ratio = 0.5375;
- log10 viscosity radius = 0.0512.

Within the common robust-admissible set, `WO_INV_0420` has nominal rank 4 but robust rank 1; the L1 winner `WO_INV_0579` falls to robust rank 6.

## Ranking propagation

Across the 117 robust-admissible candidates:

```text
Spearman rho = 0.985081
Kendall tau  = 0.891836
367 / 6786 pairwise inversions = 5.408%
```

Thus the uncertainty transformation preserves the global ordering strongly while changing the top decision. This is a **decision-frontier reshuffling under strong global rank preservation**, not a collapse of the nominal screening model.

## Rank-preservation control

Within the fixed PPG1000/PPG700 = 50/50 family for NCO:OH = 1.8–2.5 (eight robust-admissible points):

```text
Spearman rho = 1.000
Kendall tau  = 1.000
pairwise inversions = 0
```

The robust transformation therefore does not mechanically manufacture rank inversions.

## Backward design and reachability

For the property-winner 50/50 PPG1000/PPG700 blend,

```text
mdi_parts = 30.3875 * NCO:OH
```

on the frozen design grid. Solving the 35 wt% MDI floor gives

```text
NCO:OH* = 1.7719836724
```

and projection onto the 0.1-spaced grid gives the first reachable formulation at

```text
NCO:OH = 1.8 -> WO_INV_0420
```

which is also the L2 robust winner. The final robust decision therefore has a direct backward interpretation as the first reachable correction of the property optimum across the active MDI boundary.

## Local trends

At PPG1000/PPG700 = 50/50, synthetic eta80 decreases as NCO:OH increases. At fixed NCO:OH = 1.8 in the PPG700/PPG1000 family, increasing PPG700 decreases synthetic eta80. These are benchmark-surface trends and are not used as empirical polyurethane evidence.

## Version boundary relative to PUR-ORACLE V2

Historical PUR-ORACLE V2 mixed an uncertainty-interval requirement into its hard-gate definition and reported 117 candidates under that historical definition. Those files remain frozen for provenance.

PUR-FRONTIER V1 intentionally separates:

- L1 nominal point-response feasibility: 141 candidates;
- L2 uncertainty/domain robustness: 117 candidates.

The historical constrained winner remains `WO_INV_0579`; FRONTIER V1 adds a separately versioned robust layer rather than retroactively rewriting ORACLE V2.

## Reproducibility

The 928-response snapshot is stored losslessly as contiguous XZ/base64 shards:

```text
data/pur_sim_v1/candidates_full.csv.xz.b64.part00
...
data/pur_sim_v1/candidates_full.csv.xz.b64.part03
```

`pur_science.dataio.materialize_pur_sim_v1` reconstructs the CSV and verifies SHA256

```text
d8623116c6a2f60c9e022e52eeb6540573dd9434b5e507c79701abb55635bcd9
```

before the frontier is frozen. The GitHub workflow regenerates the frontier and Figure 5 from this snapshot on a fresh runner.

## Claim boundary

`PUR_SIM_V1` is a synthetic deterministic benchmark. PUR-FRONTIER V1 supports finite-space optimization, ranking propagation, constraint handling, interval robustness, backward design and Agent-recovery benchmarking. It is not experimental evidence for physical polyurethane rheology.
