# PUR-FRONTIER V1 — deterministic decision frontier

Frozen definition: `configs/frontier_v1.json`. Implementation: `src/pur_science/`. Frozen compact outputs live in `results/frontier_v1/`; the complete frontier table is regenerated by `scripts/freeze_frontier_v1.py`.

PUR-FRONTIER V1 builds on the historical PUR-ORACLE V2 benchmark without rewriting it.

## Scientific question

The decision problem is deliberately decomposed:

```text
property optimum
    -> nominally feasible optimum
    -> uncertainty-robust decision optimum
    -> active boundary
    -> backward threshold
    -> reachable formulation
```

The key question is not only which candidate wins, but why the winner changes between layers and whether the required correction lies on the admissible formulation manifold.

## Frozen layers

| Layer | Candidate set | Score |
|---|---|---|
| L0 property-only | all 928 candidates | `J = sum_k w_k log10(y_k/c_k)^2`, with preferred-window geometric centres `c_k` |
| L1 nominal constrained | point responses pass broad and preferred rheology windows, NCO:OH, MDI fraction and chemistry-domain gates | same nominal `J` |
| L2 robust | L1 candidates whose full uncertainty intervals remain inside the broad functional windows and `domain_ratio <= 1.0` | exact interval worst case of the same nominal objective |

The L2 score is

```text
J_wc = sum_k w_k (abs(log10(y_k/c_k)) + q_k r)^2
```

where the stored candidate radius is `r`, with frozen response multipliers

```text
q_eta80 = 1
q_eta120 = 1
q_ratio = 2
```

The ratio multiplier follows directly from conservative propagation of `ratio = eta80/eta120`. The original source interval columns reproduce `log10(eta80) +/- r`, `log10(eta120) +/- r`, and `log10(ratio) +/- 2r` to numerical precision.

No additional uncertainty weight or probability distribution is introduced. The same objective weights used by L0/L1 are inherited by L2.

## Why the broad window, not the preferred window, is the robust certification envelope

The preferred windows define the optimization target. They are intentionally narrow. Requiring an entire candidate uncertainty interval to stay inside all preferred windows produces zero robust-feasible candidates in the frozen 928-candidate space and therefore does not define a usable decision frontier.

The broad windows instead represent the frozen functional envelope. FRONTIER V1 therefore requires the complete uncertainty interval to remain inside the broad windows and then minimizes the worst-case distance to the preferred centres. This separates two questions:

1. does the uncertain response remain functionally admissible?
2. among admissible candidates, which has the best worst-case target proximity?

## Frozen decision chain

The complete 928-row response snapshot gives:

```text
L0 property winner      WO_INV_0419
L1 constrained winner   WO_INV_0579
L2 robust winner        WO_INV_0420
```

Counts:

```text
928 total candidates
141 L1 nominally feasible
117 L2 robust-admissible
```

### L0 — property optimum

`WO_INV_0419` is PPG1000/PPG700 = 50/50 at NCO:OH = 1.7. Its nominal objective is `6.3152e-05`, but its MDI fraction is only `0.340625`, below the frozen 0.35 floor. Its only nominal failure is therefore the MDI-fraction constraint.

### L1 — nominal constrained optimum

After point-response chemistry/process gates, `WO_INV_0579` is the nominally feasible winner. It is PPG2000/PPG400 = 60/40 at NCO:OH = 1.7, with nominal score `4.1602e-04`.

### L2 — robust decision optimum

After broad-window interval certification and domain control, 117 candidates remain. Their robust ranking selects `WO_INV_0420`, PPG1000/PPG700 = 50/50 at NCO:OH = 1.8:

- nominal rank within the robust-admissible set: 4
- robust rank: 1
- nominal score: `8.3519e-04`
- worst-case robust score: `2.1897e-02`
- MDI fraction: `0.353577`
- eta80: `3.3376 Pa s`
- eta120: `0.4035 Pa s`
- eta80/eta120: `8.2714`
- domain ratio: `0.5375`
- log10 viscosity uncertainty radius: `0.0512`

The L1 winner `WO_INV_0579` falls to robust rank 6.

## Ranking propagation and decision-frontier inversion

On the common 117-candidate robust-admissible set, nominal and robust rankings remain strongly correlated:

```text
Spearman rho = 0.985081
Kendall tau  = 0.891836
367 / 6786 pairwise inversions = 5.408%
```

Thus uncertainty propagation does not globally destroy the nominal ordering. Nevertheless, the top decision changes from `WO_INV_0579` to `WO_INV_0420`.

This is a decision-frontier reshuffling under strong global rank preservation, rather than a collapse of the nominal rheology ranking.

## Rank-preservation control

Within the fixed PPG1000/PPG700 = 50/50 chemistry family over NCO:OH = 1.8–2.5 (eight robust-admissible points):

```text
Spearman rho = 1.000
Kendall tau  = 1.000
pairwise inversions = 0
```

The robust transformation therefore does not mechanically manufacture ranking inversions. Inversion occurs where uncertainty/domain structure changes relative risk near the decision frontier.

## Backward design and reachability

For the L0 property winner blend, the frozen grid obeys

```text
mdi_parts = 30.3875 * NCO:OH
```

with polyol basis `B = 100`. Solving the MDI-fraction floor `f = 0.35` gives

```text
n* = f B / (k_blend (1-f)) = 1.7719836724
```

The next reachable point on the frozen NCO:OH grid is

```text
NCO:OH = 1.8 -> WO_INV_0420
```

which is exactly the L2 robust winner. The final robust decision therefore has a direct backward interpretation: it is the first reachable correction of the property-optimal 50/50 formulation across the active MDI boundary.

## Local response directions at the robust winner

At fixed PPG1000/PPG700 = 50/50, eta80 decreases as NCO:OH increases. At fixed NCO:OH = 1.8 within the PPG700/PPG1000 composition family, increasing PPG700 decreases eta80 (equivalently, increasing PPG1000 increases eta80).

These are deterministic local trends of the synthetic benchmark surface and are not used as empirical rheology evidence.

## Version boundary relative to PUR-ORACLE V2

Historical PUR-ORACLE V2 mixed an uncertainty-interval criterion into its hard-gate definition and reported 117 candidates under that historical gate set. Those artifacts remain frozen for provenance.

PUR-FRONTIER V1 intentionally separates:

- L1: nominal point-response feasibility — 141 candidates;
- L2: uncertainty/domain robustness — 117 candidates.

The historical constrained winner remains `WO_INV_0579`; FRONTIER V1 adds a separate robust decision layer and does not retroactively rewrite the old benchmark.

## Reproducibility

The complete response table is versioned losslessly as four XZ/base64 text parts under `data/pur_sim_v1/candidates_full_parts/`. `scripts/freeze_frontier_v1.py` reconstructs the 928-row CSV, verifies SHA256 `d8623116c6a2f60c9e022e52eeb6540573dd9434b5e507c79701abb55635bcd9`, checks design descriptors against `design_space_928.csv`, and then regenerates the frontier.

CI independently verifies the candidate counts, three winners and backward threshold on a fresh clone.

## Claim boundary

PUR_SIM_V1 is a synthetic deterministic benchmark. PUR-FRONTIER V1 supports finite-space optimization, ranking propagation, constraint handling, interval robustness, backward design and Agent-recovery benchmarking. It must not be presented as experimental evidence for polyurethane physics.
