# Material-equivalence hard gate

E1–E5 are not repeated. However, an E6* absolute-viscosity result can only be interpreted against those historical anchors if the materials used for E6* are sufficiently faithful to the patent-defined chemical system.

## Hard requirements before calling E6* a missing-cell validation

1. **Polyester chemistry identity**: the disclosed monomer families must be matched. Property-only lookalikes are insufficient. In particular, Polyester C must include the disclosed HPHP-type component; a modern polyester with similar Tg/OH but a different backbone cannot silently substitute.
2. **OH values**: actual batch COAs must be recorded and used to calculate the MDI charge/NCO:OH ratio.
3. **MDI**: use 4,4'-MDI and record actual NCO content.
4. **PPG**: use genuine PPG-425 (not automatically PPG-400) and record OH/water.
5. **Tackifier**: because the original Hercules beta-pinene grade is not disclosed, the exact modern grade must be named. This unavoidable uncertainty is reported as a limitation/surrogate axis.
6. **Disclosed physical specification check**: molecular weight, Tg, 130 C viscosity and crystallinity should be compared with the historical specification table and deviations reported before synthesis.

## Agent behavior

- **ANCHOR_COMPATIBLE**: proceed with E6* and interpret against the preregistered 44.65 vs 29.45 Pa.s hypotheses.
- **SURROGATE_ONLY**: E6* may be synthesized, but label it a specification-matched surrogate transfer test; do not claim exact missing-cell completion.
- **AUDIT_REQUIRED**: resolve critical raw-material identity/COA evidence first.
- **INCOMPATIBLE**: do not spend the experiment on E6* as a patent-mechanism test. The Agent abstains and requests a different modern-system prospective design.

This gate replaces the scientifically weak strategy of repeating E1–E5 merely to compensate for uncertain raw-material identity.
